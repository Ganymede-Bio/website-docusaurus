### August 06 2026

**Features**
- **File Browser**: Users can now filter files by file type (e.g., CSV, PDF) in the Files page advanced search, including an option to find files with no extension.
- **Dashboards**: Added a new Modular Analysis App Usage Dashboard, giving each tenant visibility into weekly session activity, session duration, and usage trends across their Modular Analysis apps.

**Improvements**
- **Web UI / Help Menu**: The Help menu's "Report a bug" option is now labeled "Contact Support / Report an Issue" to better reflect that it can be used for more than bug reports.

**Bug Fixes**
- **Dashboards / Agent Host Metrics**: Fixed an issue where the "Files Seen by Connection" chart could remain blank for connections that upload files on a schedule rather than through file watching.
- **Agents**: Fixed an issue where saving changes in an agent processor could show an "Error committing file" message even though the commit succeeded.

**Gateway Version**: 5.6.66
