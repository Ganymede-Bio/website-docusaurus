## Overview

The <div className="button darkblue_button"><TableOutlined /> **Data Explorer**</div> page offers access to tabular data generated from Ganymede flows or from other sources. To open it, go to **Data > Data Explorer**.

<img alt="Data Explorer" src="https://ganymede-bio.mo.cloudinary.net/apiServer/DataExplorer_20230831.png" />

- The **Explorer** pane contains a list of tables in the current environment, sorted alphabetically by default.
  - There is a search bar to filter the list to tables that contain the given search string.
  - There is an <img className="inline-img" alt="Add Table" src="../../img/data/addTableButton.png"/> button that lets you create a new table with a name and schema that you specify, using the [Table Structure Editor](#table-structure-editor).  This can be useful for declaring the types in a table, rather than having to infer them from the data.
- The rest of the window has various tabs that let you view or modify the selected table.
  - The **Fields** tab lets you view and edit the table structure (the defined columns of the table, aka schema) and other table metadata, including a description.

  <img alt="Data Explorer - Fields" src="https://ganymede-bio.mo.cloudinary.net/apiServer/DataExplorerFields_20231108.png" />

    - Each field has a **Name**, a **Type**, a **BigQuery name**, a **BigQuery type**, a **Required** flag, an optional **Description**, and an optional **Unit**. **Name** and **Type** are the column name and data type you use when you work with the data in pandas. **BigQuery name** and **BigQuery type** are the column name and data type in the database; use the BigQuery name in SQL queries.
    - If the table is partitioned, the **Partitioning** entry above the fields shows the partitioning column (or ingestion time) and granularity. If it also shows **Partition filter required**, queries on the table must filter on the partition column. Stream tables require a filter on `dt`, the hour in which Ganymede received each row. Stream tables are created automatically the first time data arrives, either through the [`streamData`](/api#tag/Tables/streamData) endpoint of the Public API or from an OPC-UA Subscription Connection, which streams into `opcua_<connectionId>`; see [OPC-UA Subscription Agents](../agents/OpcUaSubscription#where-readings-are-stored).
    - You can edit a schema with the [Table Structure Editor](#table-structure-editor) <img className="inline-img" src="../../img/data/editButton.png"/> button. In Edit mode, you can edit the table description, and add fields and change some of the field information. 

  - The **Preview** tab displays up to 10 rows of the selected table. For stream tables and partitioned tables, the preview uses the same recent-time filter as the default query in the **Query** tab.
  <img alt="Data Explorer - Preview" src="https://ganymede-bio.mo.cloudinary.net/apiServer/DataExplorerPreview_20231108.png" />

  - The **Query** tab allows you to do SQL queries on the table.

  <img alt="Data Explorer - Query" src="https://ganymede-bio.mo.cloudinary.net/apiServer/DataExplorerQuery_20231108.png" />

    - You specify the query in the **Query editor** pane, which is preloaded with a default query for the selected table: `` SELECT * FROM `table_name` LIMIT 25; ``. In the query, table names should be surrounded with backticks. Only `SELECT` statements are allowed.
    - For stream tables, the default query adds `WHERE dt >= TIMESTAMP_SUB(CURRENT_TIMESTAMP(), INTERVAL 24 HOUR)`. For partitioned tables, it adds a filter on the partition column that limits the query to recent data: the last 24 hours for Hour granularity, 7 days for Day, 30 days for Month, and 365 days for Year.
    
    - The **Results** pane shows the result of the query. There is a download button on the top right which will produce a CSV file based on the results.

  - The **Flows** tab shows Ganymede Flows that are associated with this table. Clicking on the links in the Flow Id column will take you to the appropriate page.

  <img alt="Data Explorer - Flows" src="https://ganymede-bio.mo.cloudinary.net/apiServer/DataExplorerFlows_20231108.png" />

### Table Structure Editor

The Table Structure Editor is accessed via the  <img className="inline-img" src="../../img/data/editButton.png"/> button in the Data Explorer **Fields** tab. You need the Writer role or higher to create or edit a table.

In Edit mode, you can edit the table description, and add fields and change some of the field information. 

For a new field, you set the **Name**, **Type**, **BigQuery name**, **BigQuery type**, **Description**, and **Unit**. The BigQuery type defaults to STRING. BigQuery names can contain only letters, numbers, and underscores, and names and BigQuery names must be unique within the table. You can mark a field as **Required** only when you create the table.

For existing fields, you can edit only the **Description**. You _can't_ delete existing fields or change their names, types, unit, or **Required** flag, so many options are disabled. This reflects consistency rules enforced by the data lake.

<img alt="Table Structure Editor" src="../../img/data/schemaEditor.png"/>

Add fields with the <img className="inline-img" src="../../img/data/newFieldButton.png"/> button. This will add a blank row to the end of the list of fields. Fields that have not been saved can be deleted with the <DeleteOutlined/> icon. When you are done editing, click  <img className="inline-img" alt="Save" src="../../img/data/saveButton.png"/> to save your changes, or <img className="inline-img" alt="Cancel" src="../../img/data/cancelButton.png"/> to discard them.

#### Partitioning a table

You can partition a table only when you create it. Partitioning can improve query performance and reduce costs for large tables.

1. Check **Enable table partitioning**.
2. For **Partition by**, choose one of the following:
   - **Column**: partition on a TIMESTAMP, DATE, or DATETIME column. Select the column as the **Partition field**.
   - **Ingestion time**: partition on `_PARTITIONTIME`, a column that BigQuery generates automatically.
3. Choose a **Granularity**: Hour, Day, Month, or Year.

### Deleting a table

You need the Admin role to delete a table.

1. Select the table and click the delete icon ( <DeleteOutlined/> ) next to the table name.
2. Type the table name to confirm, and then click **Delete**.

Deleting a table is permanent. It removes the table and all its data.

### Managing tables with the Public API

You can also create, update, and delete tables with the [Tables endpoints](/api#tag/Tables) of the Public API (`createTable`, `updateTable`, and `deleteTable`). To write rows in real time, use the [`streamData`](/api#tag/Tables/streamData) endpoint. If the table doesn't exist yet, `streamData` creates it as a stream table. To get an API key, see [API Setup](../configuration/APISetup).

### GxP validated tables

Tables that are centrally managed as GxP validated assets show a **GxP Validated** badge. You can't edit or delete these tables, but you can still view and query them. See [GxP-validated assets](../admin/GxPValidation#gxp-validated-assets).
