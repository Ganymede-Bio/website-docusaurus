The <div className="button darkblue_button"><HomeOutlined /> **Home**</div> page serves as the central hub for accessing and managing flows and Agents in your environment.

<img width="1302" alt="Home" src="https://storage.googleapis.com/ganymede-bio-website/public/apiServer/HomeScreen_20240812.png"/>
<br /><br /> 

The Home page has two sections:
- **Flows** - Cards for the flows in the environment. This section appears only in environments with Flows enabled.
- **Connections** - Cards for Connections that recently uploaded files, with Live Connections first and the most recent uploads first within each status. Click **See all Connections** to open the [Connections](./agents/AgentMonitoring.mdx) page, or **See all recent files** to open the [**File Browser**](./files/FileBrowser.mdx). This section is hidden until several Connections have recently uploaded files.

## Flows

Type in the search box above the flow cards to filter flows by name. Search results come from all flows in the environment, so the **My Flows** tab is unavailable while the search box contains text.

Click the ellipsis in the upper-right corner of a flow card to open its menu:
- **Run** - Open the flow's [Flow View](./flows/FlowView.mdx) page to run it
- **Edit** - Open the flow in the [**Flow Editor**](./flows/FlowEditor.mdx)
- **Add User** - Open the flow in the **Flow Editor** with the [**Manage**](./flows/FlowEditor.mdx#managing-flows) sidebar open, where you can assign users to the flow
- **Update Flow image** - Upload a custom image for the flow card
- **Delete** - Delete the flow

**Add User**, **Update Flow image**, and **Delete** appear only for users with the Writer role or higher. For [GxP-validated](./admin/GxPValidation.mdx) flows, every item except **Run** is disabled, and you can't star the flow.

## NavBars

### Collapsible Sidebar

The navigation sidebar groups pages into collapsible sections. Click a section to expand it and see its pages. Only one section is open at a time. Use the arrow at the bottom of the sidebar to expand or collapse the sidebar. When the sidebar is collapsed, it shows only the section icons.

[<div className="button darkblue_button"><HomeOutlined /> **Home**</div>](./Home.mdx) - Home screen used to access flows to run

<div className="button darkblue_button">**Processes**</div> - Track [**Runs**, **Processes**, **Unit Operations**, **Instrument Types**, and **Instruments**](./processes/Processes.mdx). This section is hidden in environments with [GxP Validation Mode](./admin/GxPValidation#gxp-validation-mode) enabled.

<div className="button darkblue_button"><ApiOutlined /> **Connectors**</div> - Manage [**Connections**, **Hosts**](./agents/AgentMonitoring.mdx), and [**Agent Templates**](./agents/AgentTemplates.mdx)

<div className="button darkblue_button"><BranchesOutlined /> **Flows**</div> - Build flows in the [**Flow Editor**](./flows/FlowEditor.mdx) and track current and prior runs in [**Flow Runs**](./flows/FlowRuns.mdx). This section appears only in environments with Flows enabled.

<div className="button darkblue_button"><TableOutlined /> **Data**</div> - Query and manage tabular data in the [**Data Explorer**](./tables/DataExplorer.mdx), and access input and output files in the [**File Browser**](./files/FileBrowser)

<div className="button darkblue_button"><DotChartOutlined /> **Analysis**</div> - Open [**Modular Analysis**](./ma/ModularAnalysisOverview.mdx) apps, build charts on the [**Dashboard**](./visualization/Dashboards.mdx), and review [**Virtualization**](./virt/Virtualization.mdx) sessions. **Virtualization** appears only in environments with Virtualization applications set up.

### Environment Selector

Use this dropdown in the header to choose the environment you're working in. All tables, flows, and dashboards shown in the app belong to the selected environment. Environments can have a color and an icon to help you tell them apart.

Ganymede sets each environment's color and icon. To change them, click the question mark icon in the top right corner of the app and select **Contact Support**. See [Ganymede Support](./Support.mdx#ganymede-support).

### Header Navigation

The header contains the environment selector and buttons for notifications, help, and your user settings.

[<div className="button darkblue_button"><BellOutlined /> **Notifications**</div>](./flows/Notifications.mdx) - Activity (e.g. - Flow saves, Flow runs, etc.) associated with Ganymede tenant environment

[<div className="button darkblue_button"><QuestionCircleOutlined /></div>](./Support.mdx) - Help menu with links to:
- **Documentation** - Ganymede's documentation, which can also be accessed directly at [docs.ganymede.bio](https://docs.ganymede.bio/)
- [**Product Tours**](./Support.mdx#product-tours) - Guided walkthroughs of the Ganymede web app
- [**Contact Support**](./Support.mdx#ganymede-support) - Link to the Apprentice support portal

<div className="button darkblue_button"><UserOutlined /></div> - User menu, opened by clicking the bubble containing your email address:
- [**Environment Settings**](./admin/AdminControls.mdx) - Panel for configuring access to Ganymede and secrets for accessing third-party applications from Ganymede
- **Language** - Dropdown for choosing the language of the Ganymede web app: English, Spanish, Japanese, German, French, Italian, Korean, Dutch, Portuguese, Swedish, Danish, Croatian, or Chinese (Simplified)
- The current Ganymede version number. Click it to copy the version number to your clipboard.
- **Log Out** - Log out from Ganymede cloud
