Modular Analysis (MA) enables users to develop interactive web apps from Jupyter notebooks and deploy them to users in their Ganymede tenant.  These applications are natively integrated with Ganymede data storage, enabling them to present context-rich interfaces for data capture and analyses.

## Accessing Modular Analysis

To access MA, go to **Analysis > Modular Analysis** in the left sidebar.

The Modular Analysis page has two tabs:

- **Apps**: the MA applications in the environment
- **Sessions**: the MA application sessions in the environment

On the **Apps** tab, each MA application has its own card, showing the name, image, and description of the app. To launch an app, click its card. You need the Runner role or higher to launch an app.

Each card also has the following actions, which require the Writer role or higher:

- **Edit code**: edit the code behind the MA application in a Jupyter notebook
- **Edit App**: edit the name, description, and image of the app

Each card shows the app version as **Version: YYYYMMDD-HHmmssSSS**, the date and time of the last commit to the app. A new app that hasn't been committed yet shows **Pending first commit** instead of a version.

Apps that are centrally managed as GxP validated assets show a **GxP Validated** badge. You can launch these apps, but you can't edit their code or settings.



## Base Applications

Ganymede offers a set of base applications, which can be modified and adapted for your workflows.  

For example, the base bioprocess MA application could be configured with campaign and run information specific to your labs, drawing from your LIMS or metadata derived from relevant instruments.
