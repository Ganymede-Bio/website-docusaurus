The qPCR app within the Ganymede platform analyzes quantitative PCR data from gene expression and compound screening studies. It automates the Ct-based calculations used in qPCR analysis (quantitative real-time PCR), a molecular biology technique used to amplify and simultaneously detect targeted DNA molecules. The app works with Ct values from both qPCR and RT-qPCR (reverse transcription qPCR) experiments, so you can standardize analysis workflows across your organization.

## Overview

As part of the Ganymede data platform, the qPCR app combines plate visualization, ΔΔCt calculations, percent inhibition, and dose-response curve fitting in a single interface. It replaces spreadsheet calculations with a consistent method that every user applies the same way. You can normalize each target to a housekeeping gene and a control condition, exclude wells or points from the analysis, and save the state of an analysis to reload it later.

### Common Use Cases

The qPCR app supports these analytical scenarios:

- **Gene Expression Analysis** — Quantify mRNA levels with RT-qPCR relative to a housekeeping gene
- **Copy Number Variation** — Compare target levels relative to a reference gene across samples
- **Gene Knockdown Validation** — Assess RNAi or CRISPR efficiency
- **Compound Screening** — Calculate percent inhibition and fit dose-response curves to estimate IC50 values
- **Biomarker Discovery** — Compare expression profiles across conditions
- **Pathway Analysis** — Monitor gene networks and signaling cascades
- **miRNA Quantification** — Measure microRNA expression levels

The features shown below are the capabilities of the qPCR base app. Your implementation will be tailored to your specific qPCR workflows, gene panels, and analytical requirements.

## Representative Analysis Workflow

The qPCR app follows a logical workflow that guides users through data analysis:

| **Step** | **Action** | **Description** |
|:--------:|-----------|-----------------|
| 1️⃣ | **Data Selection** | Select a run from the **Available Datasets** table and load its Ct values from Ganymede |
| 2️⃣ | **Plate Review** | Review the plate layout, label wells, and exclude problematic wells |
| 3️⃣ | **Normalization Setup** | Choose a housekeeping gene, a normalization condition, and optionally an inhibition condition |
| 4️⃣ | **Analysis Execution** | Calculate ΔCt, ΔΔCt, fold induction, and percent inhibition |
| 5️⃣ | **Curve Fitting** | Fit dose-response curves, review each fit, and calculate IC50 values |
| 6️⃣ | **Save and Export** | Save the analysis state, download results as Excel files, and download curve fits as a PowerPoint file |

:::note

The workflow steps shown are representative. Your implementation will be customized to integrate seamlessly with your existing processes, performing only the relevant steps within the Ganymede app while maintaining your established laboratory workflows.

:::

## App Layout

The app has a sidebar titled **qPCR Analysis** and four main tabs:

- **Data Selection**: The **Protocol Selection** tab, where you choose a run to load, and the **Analysis Selection** tab, where you save and reload analysis states.
- **Metadata**: The **Run Metadata** table for the loaded run.
- **Plate Results**: The plate view, bar graphs, and results tables.
- **Curve Fitting**: Dose-response curve fits for each compound and condition.

After you load a run, the sidebar shows **Save Analysis**, **Selected Metadata** (the run's protocol, plate, and run ID), **Plate Controls**, **Analysis Controls: Normalization**, and **Plot Controls** sections. The collapsed **Memory Monitor** section shows the app's memory use and the Panel version, which can help you troubleshoot a slow app.

### Key Capabilities:

**Dynamic Plate Heatmap Visualization**

Choose a result in **Plot Controls** > **Select Result**, then choose **Plate Heatmap**, **Condition Result Charts**, or **Table** to display it. The available results depend on the normalization settings you choose:

| **Metric Category** | **Available Metrics** | **Use Case** |
|-------------------|-------------------|------------|
| **Basic Measurements** | CT, Delta_CT, Mean_Delta_CT | Initial data review and quality assessment |
| **Comparative Analysis** | Delta_Delta_CT, Fold_Induction, Mean_Fold_Induction | Gene expression comparisons |
| **Normalized Results** | Normalized_Fold_Induction, Mean_Normalized_Fold_Induction | Comparisons relative to the normalization condition |
| **Inhibition Analysis** | Percent_Inhibition, Mean_Percent_Inhibition, SEM_Percent_Inhibition | Knockdown and drug studies |

CT is always available. The Delta_CT results require a housekeeping gene. The comparative and normalized results also require a normalization condition, and the inhibition results also require an inhibition condition.

**Interactive Well Selection and Editing**
- **Well exclusion** — In the **Plate View**, click wells or use the box select tool to exclude them from the analysis
- **Include_Well column** — The **Results Table** shows whether each well is included
- **Point exclusion** — In **Condition Result Charts**, switch the **Chart Type** to **Scatter**, use the box or lasso select tool to select points, and click **Exclude Selected Points**. Click **Reset All** to include all points again.

**Plate Format and Layout Configuration**
- **Plate formats** — The base app displays a 384-well plate. The plate view also supports 96-well plates.
- **Plate selection** — Choose a plate in **Plate Controls** > **Select a Plate** when a run has more than one plate
- **Condition variable** — Choose the column that defines each well's condition in **Select Plate's Condition Variable**
- **Well labels** — Label and color wells by any text column with **Well Label 1** and **Well Label 2** in the **Layout Controls**

Set up the calculation in the **Analysis Controls: Normalization** section of the sidebar, then click **Create or Update Analysis**:

- **Reference gene selection** — Choose the housekeeping gene in **Select Housekeeping Gene**. ΔCt is each well's Ct minus the housekeeping gene's Ct.
- **Control condition** — Choose the baseline in **Select Normalization condition (e.g. Bottom)**. ΔΔCt is each well's ΔCt minus the mean ΔCt of the normalization condition.
- **Fold induction** — Calculated as 2^-ΔΔCt
- **Normalized fold induction** — Fold induction divided by the mean fold induction of the normalization condition

- **Replicate statistics** — The app calculates the mean and standard error of the mean (SEM) of percent inhibition for each condition

### <LineChartOutlined /> Curve Fitting

Fit dose-response curves on the **Curve Fitting** tab. Click **Create or Update Analysis** first, so the tab has results to fit.

- **Metric and model** — Choose **Percent_Inhibition** or **Fold_Induction** in **Fit Curves on**. The app fits a four-parameter logistic (4PL) model, or a three-parameter model when you turn on **Fix Hill to 1 (3PL)**. Click **Refresh Curves** to fit the curves.
- **Concentrations** — The app reads each compound's concentration from the condition name, such as `Compound1 10uM`
- **Point exclusion** — Click a point on a curve to exclude it from the fit, or click an excluded point to include it again. Excluded points are listed in the **Excluded Points** table.
- **Manual parameters** — Fix the bottom (**Fix Bottom**), top (**Fix Top**), or Hill slope (**Fix Hill Slope**) at a value you enter
- **Custom IC values** — Calculate two additional inhibitory concentrations, set in **IC Value 1 (%)** and **IC Value 2 (%)** (80% and 90% by default)
- **Fit review** — The **Fit Comparison** table shows R², minimum, maximum, Hill slope, and relative and absolute IC50 values for the current and initial fits. Click **Validate**, **Reject Inactive**, or **Reject Unreliable** to record your review of each fit.
- **Results summary** — Click **Results Preview** to see the **IC50 Results** for all compounds, and download them as a PowerPoint file

### <SaveOutlined /> Saving and Reloading Analyses

Save the state of an analysis so you or a colleague can reload it later:

- **Save App State** — Click **Save App State** in the sidebar, the **Analysis Selection** tab, or the **Curve Fitting** tab. Review the summary and click **Confirm Save**.
- **Saved contents** — A saved state records the run, your normalization selections, the excluded wells, the qPCR results, the curve fits, and who saved it and when
- **Reload** — On the **Data Selection** > **Analysis Selection** tab, select a saved state and click **Read Selected File** to restore it

In the base app, **Save App State** runs the `qpcr-save-analysis` Flow, which stores the state as a JSON file, and the app lists saved states from the `modular_app_qPCR_templates` table.

## Data Types Analyzed

The qPCR app processes and manages multiple types of qPCR data:

### Raw qPCR Data
- **Ct values** — Threshold cycle values for each well
- **Well metadata** — Well position, target, reporter, and sample or condition names
- **Treatment information** — Compound and concentration values parsed from condition names

### Processed Calculations
- **ΔCt values** — Target normalized to the housekeeping gene
- **ΔΔCt values** — Treatment relative to the normalization condition
- **Fold induction** — Linear expression differences, raw and normalized
- **Percent inhibition** — Compound or knockdown effect, with mean and SEM per condition
- **Curve fit parameters** — Minimum, maximum, Hill slope, R², and IC50 and custom IC values

### Quality Metrics

#### Curve Fit Quality Checks

The **Fit Comparison** table includes a **QC** column. By default, a fit fails the R² check when R² is below 0.6. You can then validate or reject each fit, and the review is included in the **IC50 Results** summary.

#### Replicate Handling
- **Condition means**: Results are averaged across the included wells of each condition
- **Excluded wells**: Wells you exclude in the **Plate View** are left out of the calculations
- **Excluded points**: Points you exclude from a curve are left out of that fit and listed in the results summary

### Experimental Metadata
- **Run metadata** — The **Metadata** tab shows all columns of the run metadata table for the loaded run
- **Selected run summary** — The **Selected Metadata** section of the sidebar shows the protocol, plate, and run ID

## Data Integration

The qPCR app integrates with Ganymede's data infrastructure:

### Data Management Features
- **Direct data lake connection** — The app reads qPCR data stored in Ganymede tables with SQL queries. The base app reads run metadata from the `qpcr_run_metadata` table and Ct values from the `qpcr_raw_readings` table. Update the queries in `app.py` and `data_retriever.py` to match your tables.
- **Saved analysis states** — Save and reload an analysis, including its selections, exclusions, and curve fits

### Export Capabilities

| **Export Type** | **Formats** | **Contents** |
|----------------|------------|------------|
| **Results Table** | CSV | Each well's Ct value, metadata, and inclusion status |
| **Download analysis** | Excel | One sheet per calculated result, plus the raw results |
| **Download as plate** | Excel | The selected result and plate map in plate layout |
| **Curve fitting results** | PowerPoint | One slide per compound and one slide per condition, with the IC50 results |
| **Saved analysis state** | JSON | The run, selections, exclusions, results, and curve fits |
