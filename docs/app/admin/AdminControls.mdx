The Environment Settings page enables administrators to manage user access, configure environment secrets, and view platform integration details. This page can be accessed by clicking on the bubble containing your email address in the top right corner of the top navbar and selecting Environment Settings.

The Environment Settings page has the following tabs:

- **Roles**: User roles and defaults for new users. See [Roles Panel](#roles-panel).
- **Secrets**: Environment secrets. See [Secrets Panel](#secrets-panel).
- **Versions**: Versions of the environment, Hosts, Agent Templates, and Flows. See [Versions Panel](#versions-panel).
- **Audit**: Historical activity in the environment. See [Audit Log](#audit-log).
- **Tempo**: Tempo connection settings. Shown only in Tempo-connected tenants. See [Tempo Panel](#tempo-panel).
- **Integration**: Integration details for external systems. Shown only to Admins. See [Integration Panel](#integration-panel).

## Roles Panel

The Roles panel shown below enables administrators to specify access levels for different users. The Last Seen column is populated in the permissions panel for users that have accessed Ganymede after [August 2024](../../releases/202408#august-15-2024), when the feature was introduced. The Last Activity column shows the timestamp of each user's latest auditable action.

<img alt="Admin - Access Panel" src="https://ganymede-bio.mo.cloudinary.net/apiServer/Admin_Panel_20240920.png" />
&nbsp;

There are five levels of access. Each user's role applies to a single environment.

- **Admin**: Manage the environment settings, able to manage access of others. Admins are able to create, modify, and execute Flows and Agents.
- **Writer**: Can create, modify, and execute Flows and Agents. Can bulk-edit file tags.
- **Runner**: Can execute Flows and open Modular Analysis apps, but cannot modify or create new Flows or Agents.  Can view Agent logs, Agent history, Connection statuses, and download the Gateway installer.
- **Reader**: Can observe Flows and Agents, read data, and observe environment settings, but not permitted to execute or alter Flows or open Modular Analysis apps.  Can view Agent logs and Connection history. Readers who hover over a code-edit button, such as the code editor button on a flow node or **Edit code** and **Edit App** on a Modular Analysis app card, see a tooltip asking them to contact an Admin to change their role.
- **None**: Cannot see the environment as an option in the dropdown menu.  This is relevant for providing access to a specific environment; for example, a user may have **Runner** permission for prod but **None** permission for dev if that user is not involved in development.

The New User Roles box sets defaults for new users. Only Admins can change these settings:

- **Default Role for New Users**: The role that new users get in this environment.
- **Default Dashboard Access**: The default dashboard access level: Admin, Writer, Runner, Reader, or None. This setting applies to all environments.

Admins can also click on <div className="button red_text_button"><UserDeleteOutlined /></div> to remove a user from an environment.

### Dashboard Access

Each user's role in an environment also sets their access to [dashboards](../visualization/Dashboards.mdx) in that environment. Dashboard access is scoped to the environment, so users only see the dashboards and data for environments they have access to.

- **Admin** and **Writer**: Full content and data access, including SQL Lab, datasets, and charts.
- **Runner**: Can view and run dashboards, charts, and datasets, but cannot create or edit them.
- **Reader**: View-only access to published dashboards.
- **None**: No dashboard access.

## Secrets Panel

The Secrets panel enables administrators to configure secrets that are used by Ganymede cloud to connect to external services such as Benchling or AWS.  These secrets are specific to the nodes used within a given environment (i.e. - development or production environment).
The example shown in the image below shows an environment with a AWS S3 Role ARN specified, enabling connectivity between Ganymede cloud and AWS S3 Storage when using the [S3_Read](../../nodes/App/S3_Read) or [S3_Write](../../nodes/App/S3_Write) nodes.

<img alt="Admin - Secrets Panel" src="https://ganymede-bio.mo.cloudinary.net/apiServer/SecretsPanel_20240920.png" />

Admins can add a secret by clicking **Add New Secret**, entering the **Secret Name** and **Secret Value**, and clicking **Add Secret**. Admins can also edit and delete existing secrets.

Secret names must follow these rules:

- Use only letters, numbers, underscores (`_`), and hyphens (`-`).
- Use 128 characters or fewer.
- Use a name that isn't already taken by another secret in the environment.

The secrets table lists each secret's **Name**, **Last Updated** timestamp, and **Value**.

:::note

Secrets cannot be viewed from this panel, so if a secret is lost, it can either be re-entered here or recovered by [contacting Ganymede support](../Support.mdx).

:::

Any secrets entered here will not be committed into code, but can be printed by environment users with the *Writer* or *Admin* role in notebooks.

Several features reference secrets from this panel by name:

- **Host Service Installation Identity**: The account name and password that a Windows Host's Gateway service runs as. See [Set a Service Installation Identity](../agents/AgentInstall.mdx#step-5-if-desired-set-a-service-installation-identity).
- **OPC-UA Connections**: The password, client certificate, and client private key for an OPC-UA server. See [Store credentials as secrets](../agents/OpcUaSubscription.mdx#store-credentials-as-secrets).
- **API keys**: Secrets whose names start with `ganymede_api_key_`. See [API Setup](../configuration/APISetup.mdx).
- **Webhook-driven Flows**: The secret name and value that authenticate events sent to the webhook. See [Configuring Webhook-Driven Flows](../configuration/GenericWebhookConfig.mdx).

You can also list, create, update, and delete secrets with the `getSecrets`, `updateSecret`, and `deleteSecret` public API endpoints. These endpoints require a user access token rather than an API key, and the list endpoint returns secret names and last-updated timestamps, never secret values.

## Versions Panel

The Versions panel displays version information for the Ganymede environment:

<img alt="Admin - Version Panel" src="https://ganymede-bio.mo.cloudinary.net/apiServer/VersionPanel_20240920.png" />

- **Environment Versions**: The version of the Ganymede app and, in environments with Flows enabled, the version of the environment
- **Host Versions**: The Runtime and Gateway versions of each Host, along with links to each Host page
- **Agent Template Versions**: The latest version of each Agent Template, along with links to the Agent Template's version history
- **Flow Versions**: The latest version of each Flow, along with links to the Flow Version History page showing commit history for each Flow. Shown only in environments with Flows enabled.

## Audit Log

The [Audit panel](../configuration/AuditLog.mdx) tracks historical activity in the environment, including user actions, resource changes, and timestamps.  The Audit Log is accessible to all users in the environment.

## Tempo Panel

The Tempo panel appears only in Tempo-connected tenants. Its **Tempo Configuration** section contains the following fields:

- **Tempo Team ID**: The Tempo team ID for the environment. The value can contain only letters and numbers.
- **Tempo API User ID**: The ID of the Tempo API service account for the environment.

All users can view these fields, but only Admins can change them. To change a value, edit the field and click **Save**.

In environments with [GxP Validation Mode](./GxPValidation.mdx#gxp-validation-mode) enabled, the **Tempo Team ID** can be set once. After a value is saved, the field is locked and shows the tooltip _Tempo Team ID is locked in GxP Validation Mode._

## Integration Panel

The [Integration panel](./ExternalPlatform.mdx) contains details about the Ganymede environment, which can be used for integration with external systems, as well as for IP whitelisting Ganymede. Only Admins see the Integration tab.
