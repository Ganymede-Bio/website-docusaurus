The <div className="button darkblue_button"><CheckCircleOutlined /> **Flow Runs**</div> page contains the current status of different Flow runs that have been executed.  To view historical runs for a specific Flow, select the Flow from the datalist in the header.

### Observing Flow Status

When no Flow is selected, the page shows a **Flow Runs Last 7 Days** chart that summarizes recent Flow runs across the environment.

The run status table displayed consists of the following columns:

- **Input File**: Input files and input parameters associated with Flow run.
- **Output File**: Output files (if applicable).
- **Run By**: Who or what triggered the Flow run, such as a user, an agent, or a cron schedule. You can filter this column by Connection.
- **Run Tag**: Run Tags associated with the Flow run.
- **Flow Run ID**: ID unique to each execution of the Flow. Two Flow runs from different Flows can have the same ID.
- **Start Time**: Timestamp of when the Flow was initiated.
- **Duration**: How long the Flow run ran.
- **Status**: The current status of the flow run instance. You can filter this column by status. Clicking the status opens the run logs. Possible status values include:
  - **Queued**: The Flow run is waiting to start.
  - **Running**: Job is in the process of running.
  - **Success**: All Nodes have run successfully.
  - **Validation Error**, **Connection Error**, or **Function Error**: At least one Node failed, and the status names the [error type](./FlowView.mdx#error-attribution) of the failure. If Nodes in the same run fail with different error types, Validation takes precedence over Connection, and Connection over Function.
  - **Platform Error**: The Flow run failed and no error type was recorded for the failure.
- **Logs**: Opens a modal with logs for each Node. For failed runs, the link reads **Error Logs**.
- **Flow Version**: The version of the Flow that ran. See [Determining what code ran](#determining-what-code-ran).

### Observing Node Status

Expanding the status box shows a list of nodes with corresponding run statuses indicated by color.  Some common color codes are:
  - ![#B22222](https://placehold.co/2x2/B22222/B22222.png) **Red**: failure after retries exhausted
  - ![#01FF70](https://placehold.co/2x2/01FF70/01FF70.png) **Light green**: currently running
  - ![#2ECC40](https://placehold.co/2x2/2ECC40/2ECC40.png) **Dark green**: successful run
  - ![#A9A9A9](https://placehold.co/2x2/A9A9A9/A9A9A9.png) **Gray**: queued; awaiting system resource to commence
  - ![#FFFF00](https://placehold.co/2x2/FFFF00/FFFF00.png) **Yellow**: failure to run on at least 1 try; awaiting retry
  - ![#9932CC](https://placehold.co/2x2/9932CC/9932CC.png) **Dark Orchid**: skipped prior to completion; this color may indicate a system resource limitation
  - ![#FFA500](https://placehold.co/2x2/FFA500/FFA500.png) **Orange**: dependency for node has failed, preventing this node from being run

### Determining what code ran

Flow runs include a link to a Flow Version, indicating which version of the Flow was executed for the given run.
