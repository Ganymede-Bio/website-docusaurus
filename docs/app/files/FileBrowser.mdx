The **Data > File Browser** page allows users to search, filter, download, and link to files within the Ganymede environment. The page has two tabs: **Files**, which lists the files in the environment, and **Manage Tag Types**, where you [configure tag types](./Tags#configuring-file-tag-types).

![Files](https://ganymede-bio.mo.cloudinary.net/apiServer/GanymedeFileBrowser_20240401.png)

The file table has the following columns: _File name_, _Creator_, _Tags_, _Created at_, _Size_, _Type_, _Origin type_, _Origin_, _Usage_ and _Field names_. See [Viewing related entities](#viewing-related-entities) for what the origin and usage columns show.

## Finding files

To locate a file by name, enter your query in the search box in the upper left corner of the page and press Enter. To filter by file properties or [File Tags](./Tags), click **Advanced Search**. To remove the search and all filters, click **Clear Filters**.

To save or share the current search, click the copy icon next to **Advanced Search**. This copies the page URL, including the search and filters, to your clipboard. Bookmark the URL or send it to other users in the same Ganymede environment.

If a search takes too long to complete, the File Browser shows a warning. Narrow the results by adding a **Created at** date range in Advanced Search, and then search again.

### Advanced Search

The advanced search panel allows you to filter files by various file characteristics or [File Tags](./Tags).  To use this feature, define tag types on the [Manage Tag Types panel](./Tags#configuring-file-tag-types), and assign tags to files [in the File Browser](#editing-tags) or with the methods in the [file_tags module](../../sdk/FileTags) of the Ganymede SDK.

![Advanced Search](https://ganymede-bio.mo.cloudinary.net/apiServer/AdvancedSearch20240507.png)

The Advanced Search panel has three sections:

- **Recent Tags**: Recently used tags. Click a tag to add it as a filter.
- **Tag filters**: Click **Add Tag Type** and choose a tag type, and then select one or more values. Use **Search Tag Value** to find a value. If you don't select a value, files with any value of that tag type match.
- **File metadata filters**: Filter by **Creator**, **Created at** date range, **Size**, **Origin Type**, **Origin**, **Usage**, **Field Name** and **File Type**. For **Size**, set a **Min**, a **Max** or both. To find files used in a specific flow run, type at least 6 characters of the run ID in the **Usage** filter.

After you set your filters, click **Search**. To reset them, click **Clear Filters**.

Searches combine conditions across fields with an AND logic, while conditions within the same field use OR logic. For example, searching for files with the "LC" and "MS" instrument tags will return files tagged with either "LC" or "MS" (or both). Adding a minimum size of 1 MB will further narrow the results to files with the "LC" or "MS" tags that are also larger than 1 MB.

To filter by file extension, such as CSV or PDF, select one or more values in the **File Type** filter. Select **No extension** to find files that don't have an extension.

Archived files are hidden from search results by default. To include them, check **Include archived files**. See [Archiving files](#archiving-files).

You can't filter files by Virtualization session.

## Selecting files

To act on several files at once, select them with the checkboxes in the file table. The buttons above the table (**Archive Files**, **Edit Tags**, **Download All** and **Run Application**) apply to the selected files. Hover over a disabled button to see why it's unavailable.

## Downloading files

To download a file, click the file's name in the _File name_ column.

To download several files as a single zip file, select two or more files and click **Download All**. Keep the page open while Ganymede prepares the download; the zip file downloads when it's ready. A bulk download is limited to 2 GB. For larger selections, download the files individually.

## Editing tags

You need the Writer role or higher to edit tags.

To add or remove [File Tags](./Tags) on files:

1. Select up to 100 files and click **Edit Tags**.
2. In the **Bulk File Tag Edit** dialog, choose a **Tag Type**, enter a **Tag Value** and click **Add**. Repeat for each tag you want to add.
3. To remove a tag, click the remove icon on the tag in **Current Tags**. Removed tags move to **Tags to Remove**.
4. Click **Apply**.

If a tag type doesn't allow multiple values, you can't add a second tag of that type to a file. When strict mode is enabled, the dialog shows **Strict Mode Enabled**, and you can add tags but can't remove existing ones. Admins can turn off strict mode on the [Manage Tag Types](./Tags#configuring-file-tag-types) tab.

## Archiving files

Archiving hides files from the File Browser without deleting them. You need the Admin role to archive or restore files.

To archive files, select up to 100 files and click **Archive Files**, then confirm. To restore archived files, check **Include archived files** in [Advanced Search](#advanced-search), select the archived files and click **Archive Files**, then confirm. Select either only archived files or only files that aren't archived; you can't mix the two.

## Running an application

To open a [Virtualization](../virt/Virtualization) session with files from the File Browser, select the files, click **Run Application** and choose an application. The selected files are passed to the session. You need the Runner role or higher to run an application.

## Linking to files

To copy a link to a file, click the link icon ( <LinkOutlined /> ) next to a file's name in the _File name_ column.  This link can be shared with other users in the same Ganymede environment.  Visiting the link will open the File Browser filtered to show only the linked file.

### Deep Links - URLs for Accessing Ganymede Files from Other Apps

You can generate URLs for files using the [get_file_url function](../../sdk/FileTags#get_file_url) in the Ganymede SDK. This function returns a URL that users can use to directly access the file from another application, such as another LIMS system.

```python
from ganymede_sdk.storage import get_file_url

bucket = 'input' # or 'output'
filename = 'sample_file_name.txt'
file_url = get_file_url(filename=filename, bucket=bucket)
```

:::note

Accessing a Ganymede file URL requires the user to be authenticated in Ganymede.  If you're having trouble accessing a file URL, log in to your
Ganymede tenant in a separate Google Chrome browser tab and try again.

:::

## Viewing related entities

For each file, the File Browser shows where the file came from and where it was used:

- _Origin type_: How the file reached Ganymede: Web upload, Connection upload, API upload, Flow output or App output.
- _Origin_: The name of the Flow and Flow Run, the Connection, or the Virtualization session that created the file.
- _Usage_: The Flows and Flow Runs, and the Virtualization sessions, that used the file.
- _Field names_: The names of the flow parameters the file was passed to or produced by.

Click a name in the _Origin_ or _Usage_ column to open that Flow, Flow Run, Connection or Virtualization session.

![Files (usage)](https://ganymede-bio.mo.cloudinary.net/apiServer/Files-Usage-2023-08-31.png)

## Refreshing

The indicator below the file table shows how many files are loaded and when the File Browser last retrieved the list of files, in the form _Showing X of N files, last refreshed_ followed by a timestamp. If more than 10,000 files match (or more than 1,000 when filters are applied), the total shows as _many_. To check for newly added files, click the <div className="button darkblue_inverted_button"><SyncOutlined /> Refresh</div> button.
